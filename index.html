Guide de démarrage rapide

Suivez ces 3 étapes pour installer et utiliser DocuTech :

1
Prérequis
Node.js v18+ ou Python 3.10+
2
Télécharger
Récupérez les scripts ci-dessous
3
Lancer
npm start ou python hardware_setup.py

Exemples de code

// JavaScript - Utilisation du SDK DocuTech
import { DocuTechClient } from 'docutech-sdk';

const client = new DocuTechClient({
  apiKey: 'your-api-key',
  baseUrl: 'https://ravietech.github.io/docutech'
});

async function init() {
  const docs = await client.getDocs('guide');
  console.log(docs);
}
# Python - Configuration matériel I2C
import board
import busio
import json

i2c = busio.I2C(board.SCL, board.SDA)
devices = i2c.scan()
print(f"Périphériques détectés : {[hex(d) for d in devices]}")
