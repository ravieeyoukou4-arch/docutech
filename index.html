Guide de démarrage rapide

DocuTech fournit une documentation claire pour vos projets. Voici comment commencer :

1
Prérequis
Node.js v18+ / Python 3.10+
2
Installation
Téléchargez et exécutez le script
3
Premier lancement
npm start

Installation

Exécutez le script d'installation pour configurer automatiquement l'environnement :

# Télécharger et exécuter
node install.js

# Ou avec Python
python hardware_setup.py

Le script va :

  • Vérifier les prérequis (Node.js, npm, Python)
  • Créer la structure du projet
  • Installer les dépendances
  • Générer la configuration

API Reference

Le SDK DocuTech expose les méthodes suivantes :

// Initialisation
const client = new DocuTechClient({
  apiKey: 'your-api-key',
  baseUrl: 'https://api.docutech.io'
});

// Méthodes disponibles
await client.getDocs(section);     // Récupérer une doc
await client.search(query);        // Rechercher
await client.download(file);       // Télécharger un fichier

Exemples de code

JavaScript / Node.js
const { DocuTechClient } = require('docutech-sdk');

const client = new DocuTechClient({ apiKey: process.env.API_KEY });

async function main() {
  const guide = await client.getDocs('getting-started');
  console.log(guide);
}

main();
Python
from docutech import Client

client = Client(api_key="your-api-key")
guide = client.get_docs("getting-started")
print(guide)
cURL
curl -X GET https://api.docutech.io/v1/docs/guide \
  -H "Authorization: Bearer your-api-key"

Configuration matérielle

Pour les projets embarqués (Raspberry Pi, Arduino, ESP32) :

# Détection automatique I2C/GPIO
python hardware_setup.py

# Génère hardware_config.json
{
  "i2c": { "devices": ["0x48", "0x3c"] },
  "gpio": { "pins": [17, 18, 22] },
  "network": { "ip": "192.168.1.100" }
}
