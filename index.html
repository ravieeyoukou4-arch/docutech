🚀 Guide de démarrage rapide

  1. Prérequis – Node.js v18+ ou Python 3.10+
  2. Installation – git clone https://github.com/exemple/docutech.git
  3. Configuration – Copiez .env.example vers .env
  4. Lancement – npm start ou python app.py

💻 Exemples de code

// JavaScript - Initialisation SDK

const client = new Client({
  apiKey: 'your-api-key'
});

  return await client.getDocs('guide');
}
