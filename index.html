🚀 Quick start

Installez et utilisez DocuTech en 2 minutes :

1️⃣ Installation
npm install -g docutech-cli
2️⃣ Initialisation
docutech init mon-projet

Installation complète

# Télécharger le script d'installation
curl -fsSL https://ravietech.github.io/docutech/install.js | node

# Ou manuellement
git clone https://github.com/ravietech/docutech.git
cd docutech
npm install
npm start

API Reference

// Initialisation
const client = new DocuTechClient({
  apiKey: 'docu_sk_live_xxxx',
  baseUrl: 'https://api.docutech.io/v2'
});

// Récupérer les documents
const docs = await client.documents.list();
const guide = await client.documents.get('getting-started');

// Recherche
const results = await client.search({ q: 'installation' });

Exemples de code

// JavaScript - SDK DocuTech
const { DocuTechClient } = require('docutech-sdk');

async function main() {
  const client = new DocuTechClient({ apiKey: 'docu_sk_live_xxxx' });
  const docs = await client.documents.list();
  console.log(`📄 ${docs.length} documents`);
}
main();
# Python - SDK DocuTech
from docutech import Client

client = Client(api_key="docu_sk_live_xxxx")
documents = client.documents.list()
print(f"📄 {len(documents)} documents")
# cURL - API directe
curl -X GET https://api.docutech.io/v2/documents \
  -H "Authorization: Bearer docu_sk_live_xxxx"

Foire aux questions

❓ Comment installer DocuTech ?
Exécutez npm install -g docutech-cli puis docutech init mon-projet. Consultez notre guide d'installation pour plus de détails.
❓ DocuTech est-il gratuit ?
Oui, DocuTech est open source et totalement gratuit. Une version enterprise avec support prioritaire est disponible sur demande.
❓ Comment configurer le matériel (Raspberry Pi) ?
Utilisez python hardware_setup.py pour la détection automatique I2C/GPIO. Un fichier hardware_config.json sera généré.
❓ Comment obtenir une clé API ?
Inscrivez-vous sur notre dashboard ou utilisez la clé de démo "docu_sk_live_xxxx" pour tester.
