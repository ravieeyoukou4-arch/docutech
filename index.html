Guide de démarrage rapide

DocuTech fournit une documentation claire et moderne. Voici comment commencer :

Étape 1
Prérequis
Node.js v18+ / Python 3.10+
Étape 2
Installation
Téléchargez et exécutez le script
Étape 3
Lancement
npm start

Installation

# Télécharger et exécuter le script d'installation
node install.js

# Ou pour la configuration matérielle
python hardware_setup.py

API Reference

// Initialisation du client DocuTech
const client = new DocuTechClient({
  apiKey: 'your-api-key',
  baseUrl: 'https://api.docutech.io/v1'
});

// Méthodes disponibles
await client.getDocs('guide');     // Récupérer la documentation
await client.search('installation'); // Recherche
await client.download('script.js');  // Téléchargement

Exemples de code

JavaScript
const { DocuTechClient } = require('docutech-sdk');

const client = new DocuTechClient({ apiKey: process.env.API_KEY });

async function main() {
  const docs = await client.getDocs('getting-started');
  console.log(docs);
}
Python
from docutech import Client

client = Client(api_key="your-api-key")
docs = client.get_docs("getting-started")
print(docs)
