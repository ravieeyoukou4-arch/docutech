🚀 Guide de démarrage rapide

Suivez ces étapes pour installer et utiliser DocuTech.

  1. Prérequis – Node.js v18+ ou Python 3.10+
  2. Télécharger les scripts – Rendez-vous dans la section Téléchargements
  3. Exécuter l'installation – node install.js ou python hardware_setup.py
  4. Lancer le serveur – npm start

💻 Exemples de code

// JavaScript - SDK DocuTech
const client = new DocuTechClient({
  apiKey: 'your-api-key',
  baseUrl: 'https://ravietech.github.io/docutech'
});

const docs = await client.getDocs('guide');
console.log(docs);
# Python - Configuration matériel I2C
import board, busio, json
i2c = busio.I2C(board.SCL, board.SDA)
devices = i2c.scan()
print(f"Périphériques : {[hex(d) for d in devices]}")
